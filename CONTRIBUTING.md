# Contributing

Use Python 3.12 and Node 22. Follow the README quick start, add focused tests for behavior changes, run Ruff, pytest and frontend lint/build/tests. Include dataset/model versions and measured evidence for modeling changes. Never tune on the held-out test set or commit secrets, personal data, large raw data or binary model bundles. Keep code changes and measured documentation consistent. Explain tradeoffs and limits in pull requests; do not claim cloud validation without actually running it.
