# Executed analysis notebooks

The committed notebooks contain actual outputs from the build. Run the training and report scripts first, then install `pip install -r notebooks/requirements.txt` and open them with Jupyter or a notebook-capable editor. They reuse `signalforge` modules and saved evidence; no separate notebook-only model logic exists. Execute from the repository root or notebooks directory. The schema/feature notebook inspects source data; the evaluation notebook loads the measured comparison and explanation/calibration figures.
